# Information
Database
Simple steps
Create a table – A table stores related information.
Create columns (fields) – Each column represents one type of information.
Create rows (records) – Each row represents one complete item/person.
Choose the correct data type – For example:
INT → numbers
VARCHAR → text
DATE → dates
DECIMAL → numbers with decimals
Use a primary key – A unique value used to identify each record.
Example: Student Database
Student_ID	Name	Age	Course	Date_of_Birth
001	John	20	IT	2006-05-12
002	Mary	21	Accounting	2005-08-20
003	Peter	19	Computer Science	2007-02-15

Here:

Columns = Student_ID, Name, Age, Course, Date_of_Birth
Rows = individual students
Student_ID = primary key
Each piece of information is stored in the correct field.

In simple words: Formatting information in a database means arranging data into tables, rows, and columns and giving each field the correct data type.
